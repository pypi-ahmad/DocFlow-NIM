Name: DocFlow NIM

Description:

## Post

I built DocFlow NIM, a document parsing app using NVIDIA's Nemotron-3.5-Parse.

Upload a PDF or image, choose the pages, and export the result as Markdown or structured JSON. You can also inspect layout annotations and process multiple documents in one batch.

The Streamlit app supports local GPU inference or NVIDIA's hosted API. There's also a Gradio demo on Hugging Face ZeroGPU for trying small batches, up to five pages per conversion.

It's still a work in progress. I'd be interested to hear how it handles your documents.

Demo: https://huggingface.co/spaces/pypi-ahmad/DocFlow-NIM

Code: https://github.com/pypi-ahmad/DocFlow-NIM
